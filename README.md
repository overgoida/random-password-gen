# Random password generator - случайный создатель пароля

## Информация об авторе
**Имя и фамилия:** Олейник Виктор
**Дата создания:** Апрель 2026

### Описание
Приложение для генерации безопасных паролей с графическим интерфейсом на базе `customtkinter`. 

**Функционал:**
- Регулировка длины (4–32 символа).
- Настройка состава: буквы, цифры, спецсимволы.
- Автоматическое сохранение истории последних 10 паролей в JSON.
- Удобный современный Dark Mode интерфейс.

### Как запустить
1. Установите библиотеку: `pip install customtkinter`
2. Запустите скрипт: `python main.py`

### Примеры тестов
- **Тест 1:** Выбрать длину 8 и только цифры. Ожидаемый результат: пароль состоит только из 8 цифр.
- **Тест 2:** Перезапуск программы. Ожидаемый результат: история предыдущих генераций загрузилась в нижнее поле.
